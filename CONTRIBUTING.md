# Contributing

This repository documents a defensive security lab. Contributions should improve reproducibility, clarity and evidence quality.

## Guidelines

- Keep documentation accurate to the tested lab state.
- Distinguish configured, locally observed, manager-received and alert-indexed telemetry.
- Include safe reproduction steps and expected benign outcomes.
- Do not add real credentials, raw private telemetry or unredacted screenshots.
- Do not recommend disabling endpoint protection or weakening security controls.
- Keep client demonstration claims scoped to capabilities that have actually been validated.

## Reporting issues

Include the affected component, software version, sanitized error output, steps to reproduce and expected versus observed behavior. Remove tokens, IPs and personal identifiers where appropriate.
